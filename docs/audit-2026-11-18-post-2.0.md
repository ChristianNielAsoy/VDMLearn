## 3. Risk Checks

### Calculators and reference cards

| Calculator        | Formula                                                                                                                        | Units                            | Source                                                                            | Test                                                              |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Drug dose         | `doseRate × weight = totalDose; totalDose ÷ concentration = volume`                                                            | mg/kg × kg → mg; mg ÷ mg/mL → mL | Plumb's Veterinary Drug Handbook, 10th ed., Dose Calculation appendix             | 3 tests in `calculators.test.ts`                                  |
| Fluid therapy     | `deficit = weight × dehydration% × 10; maint = weight × mL/kg/day × (hours/24); total = deficit + maint; rate = total / hours` | kg, %, mL/kg/day, h → mL, mL/h   | DiBartola SP. Fluid Therapy in Small Animals, 3rd ed., Ch. 1 (Elsevier, 2012)     | 4 tests                                                           |
| Pearson square    | Standard mixing formula for two feeds                                                                                          | CP%, kg                          | Cullison AE. Feeds and Feeding (Reston, 1979), Ch. 4; NRC Feed Composition Tables | unverified (test file exists, specific Pearson tests not checked) |
| Epidemiology 2×2  | Sensitivity, specificity, PPV, NPV, odds ratio, relative risk                                                                  | counts → ratios                  | Thrusfield MV. Veterinary Epidemiology, 4th ed. (Wiley, 2018), Ch. 18             | tests exist                                                       |
| Epidemiology odds | Odds ratio from exposed/unexposed                                                                                              | counts                           | Same source                                                                       | tests exist                                                       |

All 4 calculators have `verified: true` and a cited source. `CalculatorDef.verified` exists in type; a "study-only disclaimer" banner exists on mock.vue; unverified — did not confirm disclaimer is shown on calculator pages without browser testing.

### Readiness score / pass prediction

- `ReadinessReport.isEstimate: true` is in the data object (literal type, always present).
- `today.vue` shows `readinessPct`% with label "Readiness" and badge "On track / Below target".
- **No "estimate" text is visible to the user.** The score looks like a pass prediction. This contradicts evidence-adjustment #2 and the 2.1-plan requirement.

### Confidence before feedback

- **Missing.** `quiz.vue:252` wraps the confidence tap in `v-if="quizStore.answered"`. The choice buttons (`quiz.vue:179`) disable on `quizStore.answered`, then feedback slides in, then the confidence tap appears.
- Sequence: choose answer → feedback shown → confidence tap appears. Required sequence: confidence tap appears before answer reveal.
- `quizStore.submitAnswer()` accepts a `confidence` param (default 2) but `quiz.vue` calls it without passing confidence (always defaults to 2 until tap fires later).

### High-confidence wrong retest

- **Missing.** `quizStore.ts`, `sessionBuilder.ts`, `itemPriority.ts`, `caseRunner.ts` — no code re-queues an item based on confidence=3 and correct=false.

### FSRS tests

- 11 tests in `src/__tests__/fsrs.test.ts`.
- Tests verify behavioral properties (stability increases on correct review, lapses tracked, etc.).
- **Not the FSRS-5 reference vectors** from the ts-fsrs library or the original paper. The plan specified "reference-vector tests."
- SM-2→FSRS conversion test: `fromLegacyProgress` tested in `scheduler.test.ts` for SM-2; FSRS has no `fromLegacyProgress` equivalent (new cards only). Unverified whether the plan's "SM-2 conversion test" requirement is satisfied.

### Migration tests

- `backup.test.ts`: 5 tests covering v1→v2 migration as pure function tests. Comment in file: "Dexie is not available in Vitest; importBackup/exportBackup are integration-tested manually in the browser."
- **No automated migration test** running the actual Dexie upgrade on a seeded v6-or-earlier database.
- Dexie schema is now **v13** (not v9 as VDMLearn.md states). v10–v13 upgrades are additive (new tables only); no `.upgrade()` callbacks beyond v8. Migration risk is low but untested automatically.

### Mock exam with small bank

- `mock.vue` shows "No questions" badge (0 questions) and "Few questions" warning badge (< 20).
- Start button disabled when 0 questions.
- **When 1–99 questions exist:** start is allowed. `mockDraw.ts` draws up to available; exam runs with fewer than 100 items. No shortfall warning on the in-exam screen.
- `MOCK_DURATION_SECONDS = 2 * 60 * 60` **hardcoded** in `src/services/mockDraw.ts:10`. Also hardcoded as text "2 hours per block" in `mock.vue:5`. Not a user setting.
- Pass rule (75%/60%) is a user setting via onboarding. Exam date is a user setting via planner. Duration is NOT.

### Mermaid security level

- `MermaidDiagram.vue:32`: `mermaid.initialize({ securityLevel: 'loose' })`.
- `'loose'` allows arbitrary HTML in Mermaid source (labels can include `<script>`, onclick, etc.).
- Required: `'strict'` or `'antiscript'`.
- Current content is seed data only (not user-editable), so the attack surface is currently limited to malicious lesson/content-pack JSON.
