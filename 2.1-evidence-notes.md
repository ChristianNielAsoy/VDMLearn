# VDMLearn 2.1: Evidence Notes

Researched 2026-10-23 to check the learning claims behind the post-1.0 plan (docs/VDMLearn-2.0-plan.md, written BEFORE the owner's 2.0 build; compare against what 2.0 actually shipped before using its milestone list). Evidence is mostly general education and human medicine, not veterinary: treat it as extrapolation. Verdicts: STRONG / MODERATE / MIXED / UNSUPPORTED (not found).

| Claim in plan                                                 | Verdict               | What the sources say                                                                                                                                                                                                                                                          | Plan implication                                                                                   |
| ------------------------------------------------------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Practice testing + spaced practice are the best study methods | STRONG                | Dunlosky et al. 2013 rated both high utility; a 242-study meta-analysis found distributed practice d=0.85 and practice testing d=0.74                                                                                                                                         | Core of M1/M2: every lesson ends in retrieval; due queue first                                     |
| Interleaving (mixed topics) helps                             | MODERATE/MIXED        | Dunlosky: moderate utility. Meta-analysis: d=0.47 from a small sample (972 participants)                                                                                                                                                                                      | Offer mixed sessions as an option, not a forced default                                            |
| Self-explanation / "why is this true" prompts help            | MODERATE              | Dunlosky: moderate utility                                                                                                                                                                                                                                                    | Add cheap optional "explain why" prompt after answers                                              |
| Highlighting, summarizing, rereading                          | LOW utility           | Dunlosky: low                                                                                                                                                                                                                                                                 | Don't build passive highlight/reread features; turn highlights into retrieval items only           |
| Spaced repetition improves medical exam results               | MIXED (observational) | One cohort: no significant Step 1 difference; systematic review: three studies positive, others none; ~1 point per 1,700 cards in one study; a 2026 meta-analysis (SMD 0.78) is cited by secondary sites only                                                                 | Don't promise score gains; keep SRS because retrieval+spacing is strong in general                 |
| FSRS beats SM-2                                               | MODERATE              | Anki docs: FSRS needs fewer reviews than its default algorithm for the same retention; SM-2 can trap failed cards at short intervals. "30-50% fewer" is a vendor claim                                                                                                        | Keep FSRS behind a flag; verify with your own data                                                 |
| Capture confidence ratings                                    | MODERATE              | Hypercorrection: high-confidence errors are corrected more often after feedback (lab and classroom); but they return after a week unless practiced again; confidence ratings are noisy                                                                                        | Record confidence BEFORE feedback; retest high-confidence wrong answers same session and next day  |
| Mistake journal / exam wrappers                               | MIXED                 | Evidence is inconsistent; some trials found no score change; "exam autopsy" beat no feedback; explanation quality correlated with later grades but not with improvement                                                                                                       | Keep it one-tap and optional; make review = re-asking missed items; measure whether it helps you   |
| Interactive/3D visuals                                        | MIXED                 | 36-study meta-analysis: 3D d=0.30 factual, d=0.50 spatial vs 2D; lower spatial ability learners did worse; VR meta-analysis of 15 RCTs SMD 0.53; a network meta-analysis found no significant gain; realism can raise cognitive load, color-coded schematic models did better | Build 2D SVG hotspots + label-the-diagram retrieval; skip 3D/VR; use simple color-coded schematics |
| Virtual patients                                              | MODERATE              | Cook 2010: large effects vs no intervention (knowledge 0.94, reasoning 0.80), ~0 vs non-computer teaching; 2019 review: equal knowledge, better skills, and blended with traditional teaching helped                                                                          | Keep M7 as a supplement after core features                                                        |
| Readiness score / pass prediction                             | UNSUPPORTED           | Only an association: more question-bank items done relates to higher Step 1 scores. No validated predictor found                                                                                                                                                              | Show descriptive coverage and accuracy per competency; no predicted pass probability               |
| Today screen, session builder, heatmap                        | NOT RESEARCHED        | UX pattern, not evidence                                                                                                                                                                                                                                                      | Treat as design bets; track whether you use them                                                   |

## Plan adjustments

1. Keep M1/M2 (spaced retrieval + FSRS flag) as the foundation.
2. Replace "readiness score" with descriptive coverage + accuracy; no pass prediction.
3. Confidence captured before feedback; high-confidence wrong answers get extra retests.
4. Simplify M3: one-tap error reason, optional; auto review = missed items re-asked.
5. M6: label-the-diagram retrieval first; no 3D/VR.
6. Add optional self-explanation prompt.
7. Interleaving optional.
8. Log which features you use and your accuracy before/after, to see what helps you.
